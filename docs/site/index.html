FEATURES

Role-specific features

Each role has tools for its responsibilities in the maintenance workflow.

01 / REQUESTER

Report and track problems

Describe a facilities problem, follow its progress, and keep the team updated.

  • Report problems with a location, category and urgency.
  • Search and filter your own Requests.
  • Add updates and track status history.
SMART REPORT ASSISTANT

Turn a description into a structured draft, with category and urgency suggestions and questions about missing details.

02 / TECHNICIAN

Manage assigned work

Find your assigned Requests and keep a clear record of the work performed.

  • Start assigned work and record progress.
  • Log work notes and time spent.
  • Submit a resolution for Manager review.
WORK PLAN ASSISTANT

Review suggested diagnostic steps, safety checks, tools, Requester questions and evidence to collect.

03 / FACILITIES MANAGER

Coordinate maintenance

Coordinate Requests from triage and assignment through review and closure.

  • Set priority and assign Technicians.
  • Review completed work or return it for rework.
  • Manage accounts, catalogues and audit records.
TRIAGE ASSISTANT

Consider category, priority, clarification and skill-tag suggestions. The app ranks Technician candidates for you to review.

WORKFLOW

Request lifecycle

Each Request follows an explicit workflow, with status history and clear responsibility at every stage.

  1. 01Open

    A problem is reported.

  2. 02Assigned

    A Technician is selected.

  3. 03In progress

    Work and time are recorded.

  4. 04Completed

    A resolution awaits review.

  5. 05Closed

    The Manager verifies completion.

Authorised users can also cancel, reassign, return work for rework or reopen Requests where the lifecycle permits.

AI ASSISTANCE

Advisory AI

Each role has an assistant powered by the SoC LLM through SoCLaaS. Users can accept, edit or reject its suggestions.

↗

Review, edit or reject

AI drafts and recommends. It never submits Requests, changes priority, assigns work or closes Requests.

⊙

Role-based access

Server-side checks enforce role, ownership and assignment permissions before actions and AI context access.

↳

Manual fallback

The core maintenance workflow remains available when AI is disabled or unavailable.
